# Terrain Foundry 1.0.2 — guided installation and interactive updates

- A complete Windows installation wizard: welcome, publisher and licence information, installation folder, confirmation, progress and finish.
- Gold castle icons for the desktop shortcut, Start menu shortcut and launcher.
- Installation directory remembered across MSI upgrades. Launcher, client, scenery and self-updates use the selected folder.
- Startup checks for signed updates and displays release details and download size. Downloads and installation require the Install / update button.
- An approved launcher self-update restarts and continues that same approved release without asking twice.
- Reuses the verified 1.0.0 editor and 15 scenery packs. Scenes and recovery files remain separate and unchanged.

Install this MSI to get the new wizard and desktop shortcut. The first client/scenery installation needs internet. An existing editor remains available offline when an update is declined or unavailable.
