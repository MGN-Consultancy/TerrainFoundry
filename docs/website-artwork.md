# Website showcase artwork

The October 2026 showcase distinguishes concept artwork from shipped models.
All generated concepts were made using the built-in image generation tool, not a customer API key. Their captions explicitly identify them as concepts. They are not product screenshots or previews of downloadable packs.

## Final web assets and generation briefs

- `site/assets/worlds-concept.webp`: original miniature fantasy village inside a limestone cavern on a charcoal workbench; warm amber windows, cool daylight, detailed physical terrain, negative space at the left for website copy; no text, logos or interface.
- `site/assets/railway-concept.webp`: future model railway scenery concept; British country station, curved track, stone bridge, platform and signal box; tactile tabletop scale model in afternoon light; original, no brand or readable text.
- `site/assets/racing-concept.webp`: future racing scenery concept; miniature pit garages, barriers, marshal post, spectator terrace and track bend; warm afternoon light, physical hobby diorama; no branding or readable text.

WebP versions use quality 87. Source generations remain in the local generated-images archive.

## Actual product imagery

The Deepstone and Willowbrook galleries use existing renders of real assets. Basic scenery and editor images show the desktop application. Campaign screenshots were captured from the packaged 1.15.0 client using an isolated local demonstration campaign, “The Lanterns of Deepstone”, with original story text and starter sounds. No provider requests or customer campaign files were used. Screenshot WebP versions use quality 85.

Railway and racing collections are in development and are not presented as available for purchase. The homepage does not use scroll-controlled animation.
